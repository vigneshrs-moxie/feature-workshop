# Decisions

One file per ticket (or per numbered record) with the decisions made while building it (id, question, options, choice, who, when, why) and what was left out on purpose, so engineers and agents can read later why the code is the way it is. Files that span tickets are under general/. Dashboard rebuilds this table from the files: change a file, not the table.
